# 测试文档

## 快速开始

```bash
# 运行完整测试套件

# 只查看测试摘要
npm run test:summary
```

## 测试内容

本测试套件验证以下功能：

### ✅ 1. PDF 处理
- PDF 文本提取
- PDF 页数统计
- PDF 哈希值生成

### ✅ 2. AI 审核系统
- **test-funny-paper.pdf**: 正常搞笑论文应该通过审核
- **anticcp_test.pdf**: 违法内容应该被拒绝
- 评分格式验证（道德性、搞笑性、科学性）
- 测试题生成验证

### ✅ 3. 评分计算
- 最终得分公式: `(道德性 × 0.2) + (搞笑性 × 0.5) + (科学性 × 0.3)`
- 权重验证: 搞笑性占 50%（最高权重）
- 边界情况处理

### ✅ 4. 重复提交检测
- 相同 PDF 哈希值应该被拒绝
- 不同 PDF 应该有不同哈希值

## 测试文件
